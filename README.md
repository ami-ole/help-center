# ami.OLE Help Center

Tutorials, videos and the Settings Guide for ami.OLE, the overhead line equipment add-in for Autodesk Revit.

Live site: https://ami-ole.github.io/help-center/

This repository holds the built site only. It is generated by `docs/help-center/build_help.py` in the ami.OLE source repository; edit the source there, rebuild, copy `docs/help-center/site/` here and push.
